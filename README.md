# In Silico Modeling of Xylose Utilization in S. cerevisiae

This repository contains a Flux Balance Analysis script using 'cobrapy' to simulate ethanol production from xylose in a modified S. cerevisiae strain (iMM904 mode).

## Project Overview
Wild Type: Simulated with native xylose reductase (XYLP) knockout to block side pathways.
Mutant: Engineered in silico by introducing a heterologous Xylose Isomerase from Piromyces sp. E2.

## Requirements
Python 3.x
cobrapy

## Results
Wild Type ethanol flux: 20
Engineered Mutant ethanol flux: 28.3
